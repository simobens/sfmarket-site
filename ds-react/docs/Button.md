The design system's pill action: 30px radius, Josefin Sans 700 caps, accent #6e8fef with #39529a hover. `variant="ghost"` is the outlined secondary, `variant="teal"` uses the brand teal. Give it `href` to render as a link.

```tsx
<Button href="#about">Learn More About Us</Button>
<Button variant="ghost">Secondary</Button>
<Button variant="teal" block>Full-width teal</Button>
```
