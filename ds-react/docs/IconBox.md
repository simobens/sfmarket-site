Centered info block with a teal icon circle, heading and body — the original contact section's Address/Phone/Email boxes. Built-in icons: `address`, `phone`, `email`; or pass any SVG node. Lay out in an `IconBoxGroup`.

```tsx
<IconBoxGroup>
  <IconBox icon="phone" title="Phone">(+852) 3001-6327</IconBox>
  <IconBox icon="email" title="Email Address">contact@sfmarket.hk</IconBox>
</IconBoxGroup>
```
